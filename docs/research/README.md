# Civilization research index

Use Smil to reason about work, energy, production and infrastructure. Use Scott
to question how settlement, surplus and political control affect the people
doing that work. Plant supplies practical craft and shelter examples; Kelly
supplies conditional models of foraging, travel and technological investment.
Together they support meaningful choices without prescribing one inevitable tree.

Start with the [game reference guide](reference-guide.md), then follow a source
note to its cited passage. The notes separate the author's argument from its
possible use in the game.

## Open a cited passage

From the research worktree root, use Python 3.12 or newer. EPUB lookup uses only
the standard library. PDF lookup also needs [requirements.txt](requirements.txt):
`py -3 -m pip install -r docs/research/requirements.txt`, or use a configured
bundled PDF Python runtime that already provides pypdf. Lookup commands read
local files, make no network calls and write no files. Dependency installation
can contact the package index. No npm setup is needed.

```powershell
py -3 -B docs/research/read_sources.py verify
py -3 -B docs/research/read_sources.py chapters smil
py -3 -B docs/research/read_sources.py read smil 3 --paragraphs 59:61
py -3 -B docs/research/read_sources.py read scott 4 --paragraphs 29:38
py -3 -B docs/research/read_sources.py search scott "salinization" --limit 3
py -3 -B docs/research/read_sources.py read plant 6 --paragraphs 91:92
py -3 -B docs/research/read_sources.py read kelly 3 --pages 86:86
```

The `read` range is inclusive. EPUB ordinals count nonempty XHTML headings,
paragraphs, captions, list items and definition items in document order. Chapter
IDs follow each source's chapter/part index; `chapters BOOK` lists them. PDF
`--pages` always means physical file pages, never printed labels. Search limits
count matching paragraphs for EPUBs and matching pages for PDFs. A different
machine can locate the same copies with an explicit root:

```powershell
py -3 -B docs/research/read_sources.py --library-root D:/books verify
```

Each lookup checks the whole EPUB hash. A missing source, changed edition,
invalid range or mismatched chapter fails with an explanation. A zero-match
search reports zero; it does not establish that a concept is absent from the
book. Figures, tables and words split across markup may need direct inspection
in an EPUB reader. The helper does not decrypt DRM or fetch missing copies.

For broader library searches, use the Books repository's existing
[search tool and setup guide](https://github.com/step3software/books/blob/8893e4e75744f12fd3f52cc1b9f5347a11e97453/docs/library.md).
Its generated local index needs a refresh after a checkout or library change.
The small helper here resolves the four verified editions and their citations
without requiring that database.

## Reading coverage and provenance

The initial reading surveyed Smil and Scott's numbered chapters and Scott's
introduction. The extension closely reads selected Plant projects and Kelly
passages in chapters 1, 3, 4, 5 and 7. Complete EPUB part/project and PDF bookmark
structures are indexed. Selected shelter images and Kelly's printed pages 52,
64 and 129 were visually checked. Other figures, tables, endnotes and underlying
studies were not comprehensively reviewed. No cover-to-cover reading is claimed.

The source notes are original paraphrases. These sources supply
arguments and examples, not calibrated game parameters or a complete research
consensus. Plant is a practical reconstruction source; Kelly compares varied
ethnographic cases through conditional models. Smil's statistics describe the period covered by the
2017 edition. Scott flags several early-state explanations as speculative and
argues a position where evidence or interpretation is contested.

The [water extension](water.md) adds focused Plant/Smil passages and primary
archaeological, museum, engineering and public-health sources. Each web reference
has a direct URL and a consultation date; later objects illustrate properties
without dating the first invention. Its cost combinations are proposed design
options. Modern engineering examples do not establish early construction recipes.

[Run evidence](evidence.json) records the project and current Orcha revisions,
document hashes, the historical prototype observation and this extension's current-game source. Future
work resolves current standards afresh; that dated evidence is not a version pin.
