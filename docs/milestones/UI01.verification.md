## Confirmed findings, corrections and rejected hypotheses

- Vue 3's static/bound style merge precedence kept the old hidden wrapper hidden;
  actual startup failed. The redundant style pair is removed and mount-owned cloak
  prevents raw-template display. All real startup/recovery paths now pass.
- Raw restoration result escaped canonical reactivity. A focused new rule failed
  on `result.value !== saveState.player`; observing that result before activation
  preserves returned identity and subsequent caller-triggered reactive updates.
- Vue 2 dynamic component syntax, same-element loop alias scope and malformed
  table/duplicate attributes were incompatible. Actual registered templates use
  supported component/condition/table structure, compile without diagnostics and
  render the accepted middle/late component journeys. Explicit point-name spacing
  preserves readability under Vue 3 whitespace handling.
- New native navigation/menu controls needed keyboard focus/close/containment and
  narrow reflow. Selecting the existing old-style stylesheet would unload rules
  placed only in `style.css`; one shared `interface.css` now owns these adaptations.
  Both original theme files remain byte-identical. Final style checks deliberately
  enter keyboard modality; pointer-only focus is not evidence for `:focus-visible`.
- A real automation click was intercepted by passive achievement/milestone
  notifications. Their container now permits click-through; the actual ON/OFF
  automation journey passes while the notification stack is present.
- Canvas scroll handlers still named a removed global. They now invoke the owned
  canvas port. Narrow canvas rendering is clipped to the stacked tree pane and
  constrained to viewport width. Resize checks await the native asynchronous
  result rather than sampling before delivery; there are no suite retries.
- A scheduled Vue render failure occurs outside the driver callback. The app error
  handler disposes owned resources and reports through the existing reload-only
  fault gate even if cleanup throws. The synthetic rendered failure retains the
  exact prior durable string, refuses saving and recovers on real reload.

Candidate formula/balance/schema drift is rejected within the representative
coverage by protected source bytes, complete inherited AST/contracts and exact
state/save comparisons. Missing-file historical failures never count as expected
behavioral failures. Initial malformed synthetic fixtures and an export selector
that read the recovery textarea were corrected in tests; they were not production

slice failure was resolved only after proving all tracked scripts unchanged and
