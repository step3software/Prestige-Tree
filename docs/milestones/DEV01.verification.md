## Confirmed review findings and corrections

1. **Historical source mismatch:** DEV01’s original plan points to deleted
   `js/layers.js` and single-context engine globals. Preparation reconciles the
   delivered graph and preserves the original proposal/criteria/provenance.
2. **Untyped Decimal gap:** a new negative fixture initially accepted a primitive
   player-point assignment because the vendor inferred as `any`. A narrow external
   instance contract at the canonical default/cache boundaries now rejects both
   player/cache primitive substitutions. Vendor bytes and runtime hydration are unchanged.
3. **Resource lifetime gap:** initially only the browser driver was disposed by
   context disposal/restoration. The runtime owner now tracks every directly
   created handle, cancels all on replacement/disposal, invalidates the context,
   prevents reentrant creation during disposal and cleans remaining handles even
   if an onStop callback throws. Focused tests demonstrate zero remaining handles
   and harmless queued callbacks, without affecting another session.
4. **Fault-restoration bypass:** the new memory restore path initially could
   replace partial faulted state. It now rejects faulted/unloaded contexts before
   mutation, preserving the inherited reload-only protection; the regression
   asserts retained player identity/data and fault state.
5. **Cached endgame regression:** a new rendered scenario failed to reveal Keep
   Going after the rule flag changed. A rule-owned status object, observed by the
   view through the same reference, fixes the transition without changing the
   endgame formula or continue behavior. The before-failing/after-passing browser
   test now verifies both endgame display and resumed progression.

The old `player = orig` purchase assignment was removed only because `orig`
already referenced that same object; no multi-currency rollback redesign occurred.
The microtab computed property now reads its explicit `this.layer`/`this.data`
props rather than accidental free names. Candidate formula/balance drift was
rejected by complete normalized source comparisons and exact checkpoints, within
the representative coverage limit below. No consequential owner decision or
accepted-criterion reduction was needed.
